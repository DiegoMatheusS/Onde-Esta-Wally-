ONDE ESTÁ WALLY? — PROTÓTIPO WEB

COMO ABRIR
1. Extraia o ZIP inteiro para uma pasta.
2. Abra index.html no Google Chrome, Edge ou Firefox.
3. Digite o nome.
4. Escolha 3, 5, 8, 10 ou 13 fases.
5. Clique START.

RECURSOS
- 13 imagens/fases.
- Sorteio de fases a cada partida.
- Cronômetro com milissegundos.
- Ranking separado por quantidade de fases usando localStorage.
- Música gerada pelo próprio navegador, sem arquivo de áudio externo.
- Efeito de acerto e vitória.
- Imagem não arrastável/não selecionável durante o jogo.
- Cursor não muda sobre o personagem.
- Menu animado.
- Responsivo.

CALIBRADOR
Abra calibrar.html, escolha uma fase e clique exatamente no centro do Wally.
A posição é salva automaticamente no navegador.
Use as setas para avançar/voltar entre as 13 cenas.
Também é possível ajustar a largura/altura da área clicável.

As 7 imagens adicionadas nesta versão entram no calibrador e precisam ser marcadas uma vez para que a área de clique fique exata.

Para apagar a calibração de uma fase, use "Restaurar padrão".
Para apagar o ranking, use a engrenagem no menu inicial.

OBSERVAÇÃO
Este protótipo usa as imagens fornecidas para demonstração. Para publicação pública/comercial, verifique as permissões e direitos de uso das imagens/personagem.
